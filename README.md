# Invitación de Bautizo · Santiago

Invitación web (Vue 3 + Vite) en estilo acuarela, publicada en GitHub Pages.

## Personalizar

- **Nombre, fecha, lugares, padres y padrinos:** `src/datos.ts`
- **Ilustraciones (opcionales):** `src/assets/images/` con estos nombres: `santiago-portada`, `santiago-final`, `cielo`, `barquito`, `nube-1`, `nube-2`, `iglesia`, `jardin`, `paloma`, `concha`, `guirnalda-olas`, `esquina-eucalipto`, `fondo-escritorio` (`.webp` o `.png`). Si falta alguna, se usa un dibujo en el mismo estilo.
- **Fotos de la galería:** `src/assets/images/santiago1.webp`, `santiago2.webp`, … (sin fotos, la galería no aparece)
- **Música:** cualquier `.mp3` o `.m4a` en `src/assets/audio/`

## Desarrollo

```bash
npm install
npm run dev
```

Cada push a `main` se publica solo en GitHub Pages.
